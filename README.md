# UNIEP Darslar — Android ilova

University of Economics and Pedagogy masofaviy darslar platformasi uchun rasmiy Android ilova.

## 📥 Yuklab olish

**[⬇️ UNIEP-Darslar.apk ni yuklab olish](https://github.com/nnumanjanov16121999-netizen/uniep-darslar/raw/main/UNIEP-Darslar.apk)**

Joriy versiya: **1.0.21** (2026-10-30)

## O'rnatish

1. Yuqoridagi havola orqali APK faylni telefoningizga yuklab oling.
2. Faylni oching. Telefon so'rasa, **"Noma'lum manbalardan o'rnatish"**ga ruxsat bering.
3. **O'rnatish** tugmasini bosing.

Ilova yangi versiya chiqqanini o'zi aniqlaydi va yangilashni taklif qiladi.

Talab: Android 7.0 yoki undan yuqori.
